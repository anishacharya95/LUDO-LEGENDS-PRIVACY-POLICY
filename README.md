# Ludo Legends — Privacy Policy

This repository contains the public privacy policy page for the Ludo Legends Android game.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to finish publishing.

The policy page will then be available at:

https://anishacharya95.github.io/LUDO-LEGENDS-PRIVACY-POLICY/

Use that URL in the Google Play Console **Privacy policy** field.

## Before publishing the app

The policy currently documents the Google Mobile Ads SDK integration identified for Ludo Legends (app-open and interstitial ads). Review the actual release build for any additional SDKs or data flows—such as analytics, crash reporting, sign-in, multiplayer services, cloud saves, or purchases—and update the policy and Google Play Data safety form to match. Do not claim that the app collects no data unless that has been verified against the complete release build and all third-party SDKs.
